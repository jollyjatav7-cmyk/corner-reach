# 角球到达与选择

边看比赛边记录两队到了对方禁区附近以后怎么选择：传中、远射、中路渗透、回传、丢球，以及之后的内外、禁区射门、角球。这个 app 只做统计，不预测角球；数据多了以后再拿来建模型。

- 安装：用 Safari 打开这个仓库的 GitHub Pages 网址 →“分享”→“添加到主屏幕”，联网时打开一次即可离线使用。
- 两个程序（上方切换，记在同一场比赛里，可以只用一个）：
  - **到达与选择**：左边记主对客（主队进攻）、右边记客对主（客队进攻）。球队到了对方禁区附近点“到达”，秒数开始走；做出选择时点传中、远射、中路渗透、回传或丢球（app 记下用了几秒）。传中、远射接着选内或外；传中内再选禁区射门或解围/中途拦截；中路渗透选有没有禁区射门；最后选进球、角球或无角球。同一次进攻里又做了一次选择，就再按一次“到达”。不是从记下的到达直接来的角球，点“其他角球”。
  - **两个问题**：每队两个大字问题——他容不容易到对方禁区附近、他喜不喜欢传中和远射，各分 1–5 档，随时可以改。
- 第一部分（主观）：每队“到达”上方的四格——球权、到禁区附近的难度（五档）、意愿、场面，点开随时可以改，每次改都会记下时间。
- 统计：iPad 在两队中间，手机在底部“统计”。到达次数和每 10 分钟几次、五个选择的比例（每队一条＝100%）和次数、传中＋远射占比、从到达到选择的秒数、传中和远射在范围内的比例、射门、角球和角球从哪里来，两队对比，可以切换上半场、下半场、全场。
- 计时器：点比分中间的时间（或 ▶）开球、中场、对准画面上的时间；中途才开始看也可以。
- 联网（可选，免费）：直接用“角球数据记录”里的 API-Football key。输入球队中文名就自动找到这场比赛；比赛已经在踢时会弹出“中途加入”，时间、比分、角球、红牌都填好。记录时按底部“同步”才会联网（默认不自动同步，省额度），联网比你多的角球、进球、红牌会等画面追上后才补上，你自己点到了就不会重复。
- 比赛仓库：结束时选“加入仓库”，按“开始新比赛”记下一场。可以搜索、打开、导出、删除；“统计”有平均角球、你的到达和选择平均、“到达多不多 × 传中远射多不多”的角球、第一部分和两个问题每种选择下的角球；“备份”可以导出 JSON（能再导入、能传给 Claude 分析）或表格 CSV（每一笔、每队每半场）。
- 视频浮窗：一台手机边看画中画边记录时，在“功能 → 视频浮窗”选浮窗在上方或下方，app 会空出位置。
- 数据只存在设备上。跟“角球数据记录”“角球六要素”放在同一个网域，但存放位置分开，互不影响（只会读它们的 API key 和队名对照，不会改它们的资料）。
